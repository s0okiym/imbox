# Imbox 开发总结（持续开发候选）

日期：2026-10-05。本文总结当前已落地的工程，不表示 V1 已准出。完整验收仍受 [准出记录](release-readiness.md) 约束。

## 工程结构

主语言 TypeScript，Node.js 24 / Fastify 提供 API，独立 Worker 驱动持久作业，React / Vite 提供 Web/PWA。PostgreSQL 是业务权威状态，应用与身份服务使用受限独立角色；S3 兼容存储保存资源字节。精确版本在 pnpm 锁文件、Node 版本文件和 Compose 镜像摘要中固定。

仓库按应用、领域/契约/基础设施包、集成测试和运维脚本划分。接口从契约生成 OpenAPI/类型，迁移校验和防止已应用版本被改写。生产请求路径不执行迁移，不使用 owner 数据库角色。初期作业直接使用数据库事务与领取租约；与原始设计的取舍见 [实现决策](development/07-implementation-decisions.md)。

## 已落地的业务闭环

- 人际通信：OIDC、会话撤销、私聊/群聊、消息版本/固定引用/线程/反应、单调已读、持久 outbox、WebSocket 与 HTTP 补齐。长历史通过有界窗口和虚拟列表访问；消息深链仍检查当前权限。
- 协作：独立 Task ACL、唯一 owner、咨询/委派/交接、依赖防环、全祖先代际、固定产物版本与人类验收。负责人不可用和期限到达进入维护/升级流程。
- 执行：持久 Run、固定上下文与 Agent 修订、数据库时间租约、检查点、预算和未知用量。真实固定摘要本地模型接入；工具意图必须绑定授权和任务，人工批准后明确恢复，效果未知时先只读核对。
- 多 Agent：托管/外部身份、机器 HTTP API、TypeScript SDK、短期凭证与撤销、送达 ACK 与接受分离。浏览器提供注册、停用、一次性密钥显示及凭证元数据管理。
- 资源与治理：受限文本资源、不可变 Artifact 版本、评论/定向分享、显式 Memory、当前权限搜索、保留/删除、完整性可校验的导出；独立删除/撤销与行动日志参与恢复。
- 体验：中文 Web、移动布局、明确同意的离线副本/草稿/待发队列、静态应用 PWA 缓存、通知中心/DND。Web Push 加密订阅与有界投递已实现；厂商/真机送达单独验收。

## 关键正确性边界

认证上下文决定调用者；消息正文、模型输出和外部 Agent 声明均不能授予权限。读取、执行和披露分别判定，执行前重验当前身份、版本、租约与全祖先约束。审批绑定固定动作，不能作为任意工具调用的长期通行证。

业务事务与 outbox 一起提交。重复请求使用原业务身份核对；外部请求结果不明时保留 unknown 和预算，禁止以盲目重发推断结果。恢复先隔离/冻结，重放独立事实并核对已发生的外部效果。数据库恢复不能撤回外部副作用。

浏览器缓存不承担认证或授权职责。退出和清除设备数据使迟到写入失效；联网后重新验证身份与范围。离线设备无法立即获知远端撤权，这一边界在主动启用缓存时说明。

## 主体交付补齐

按“主体框架与完整流程优先”的开发顺序，新增本机集中启动器：保留既有配置、初始化基础设施/构建/迁移/种子、监督 API/Worker/Web 和可选工具执行器，检查就绪并统一停止。已实际验证双人消息送达、端口冲突拒绝以及 Worker 退出时整组退出。

新组织不再只能依赖固定开发 seed。离线 `workspace:provision` 使用已有有效 human 身份，在同一事务创建组织、工作区、唯一 owner 和初始成员，并保存仅运维可读的数据库操作者回执；同清单重试不会恢复已撤销权限。这是首次开户入口。日常管理现已接入工作区创建及已有成员的角色、停用、恢复；组织级生命周期及绑定账号的邀请也已接入，剩余范围按 [后续优先级](delivery-backlog.md) 推进。

对 41 项 AC/INV 的本轮断言审查结果为 27 项 verified、13 项 partial、1 项 pending，详见 [逐项审查](testing/acceptance-review-2026-10-04.md)。已补私聊专用回归；剩余联合故障、竞争、兼容与真实部署验证逐项保留，不把功能试用候选描述为生产准出。

组织管理进一步覆盖已有成员的组织角色任免、停用及恢复，具有所有者/管理员权限分级、最后 owner 与工作区管理员保护、CAS、幂等和独立撤权代际。新成员通过绑定账号邀请、预览和确认加入已有组织；首次创建组织仍走受控 CLI，不等同于开放自助开户。

账号与绑定邀请补齐最后一段新成员接入：未入组用户可取得本人标识、安全退出；管理员创建绑定邀请，接收人预览后确认加入。单次消费、撤销、期限、原邀请者授权代际及独立账本共同约束入组，详见 [操作说明](operations/member-invitations.md)。完整本地业务回归为 277 集成、31 浏览器通过；生产身份与部署验收仍独立保留。

## 旧执行写入与升级顺序（2026-10-05）

迁移 036 使缺少连接摘要的新授权及 prepared/in_flight 尝试在数据库提交时失败，阻止旧 SQL 形态绕过新服务检查；保留历史事实及未执行终态清理。完整工程检查（191 单元）与全量 339 集成通过。部署手册明确停止旧外部执行/恢复写入器后协调升级，回退保留约束；通信兼容不代表执行栈兼容。见 [验证范围](testing/database-binding-fence-2026-10-05.md)，剩余准出门槛保持。

历史执行兼容补验直接加载固定提交的编译 Action 服务/runner，四项真实数据库与 HTTP 场景确认旧写入拒绝、未执行清理和当前一次发送，完整兼容六场景通过。独立旧 Worker/恢复程序与生产混合部署尚未由此证明，见 [验证范围](testing/historical-action-writer-2026-10-05.md)。

## 联合故障下的消息恢复（2026-10-05）

模型请求挂起、S3 上传 503、WS 断开及投影积压的同次回归发现合法 ACK 突发被异步控制队列误判的问题。ACK 改为严格校验的本地窗口操作，保留控制队列/背压限制。60 条消息和 6 次同键重试后恢复，61 条唯一消息完整送达；模型 unknown 不重发，原上传票据可恢复。工程检查 191 单元与 32 相关集成通过，见 [故障证据](testing/joint-fault-recovery-2026-10-05.md)。长期及跨进程故障验证仍保留。

## 独立 Worker 进程崩溃恢复（2026-10-08）

联合故障回归中"暂停调用并重建处理器"的投影中断模拟升级为真实进程崩溃：独立 OS 进程内的 Worker 入口在投影中途被 SIGKILL，无失败处理器运行。验证搁置租约在到期前不被新进程窃取、到期后恰好一次重认领并完整投影，接收端 40+1 条消息无遗漏或重复。Worker 新增经校验的 `WORKER_LEASE_SECONDS`（默认 30 不变），部署示例与运维手册同步说明调整约束。同时修正 coverage.json 中 AC-14 注记滞后于 41f3e12 任务取消联动实现的问题。工程全检与 sync 全文件通过，见 [证据](testing/worker-crash-recovery-2026-10-08.md)；AC-16 剩余容量与联合故障门槛保留。
