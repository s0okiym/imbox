# Imbox 开发总结（持续开发候选）

日期：2026-10-04。本文总结当前已落地的工程，不表示 V1 已准出。完整验收仍受 [准出记录](release-readiness.md) 约束。

## 工程结构

主语言 TypeScript，Node.js 24 / Fastify 提供 API，独立 Worker 驱动持久作业，React / Vite 提供 Web/PWA。PostgreSQL 是业务权威状态，应用与身份服务使用受限独立角色；S3 兼容存储保存资源字节。精确版本在 pnpm 锁文件、Node 版本文件和 Compose 镜像摘要中固定。

仓库按应用、领域/契约/基础设施包、集成测试和运维脚本划分。接口从契约生成 OpenAPI/类型，迁移校验和防止已应用版本被改写。生产请求路径不执行迁移，不使用 owner 数据库角色。初期作业直接使用数据库事务与领取租约；与原始设计的取舍见 [实现决策](development/07-implementation-decisions.md)。

## 已落地的业务闭环

- 人际通信：OIDC、会话撤销、私聊/群聊、消息版本/固定引用/线程/反应、单调已读、持久 outbox、WebSocket 与 HTTP 补齐。长历史通过有界窗口和虚拟列表访问；消息深链仍检查当前权限。
- 协作：独立 Task ACL、唯一 owner、咨询/委派/交接、依赖防环、全祖先代际、固定产物版本与人类验收。负责人不可用和期限到达进入维护/升级流程。
- 执行：持久 Run、固定上下文与 Agent 修订、数据库时间租约、检查点、预算和未知用量。真实固定摘要本地模型接入；工具意图必须绑定授权和任务，人工批准后明确恢复，效果未知时先只读核对。
- 多 Agent：托管/外部身份、机器 HTTP API、TypeScript SDK、短期凭证与撤销、送达 ACK 与接受分离。浏览器提供注册、停用、一次性密钥显示及凭证元数据管理。
- 资源与治理：受限文本资源、不可变 Artifact 版本、评论/定向分享、显式 Memory、当前权限搜索、保留/删除、完整性可校验的导出；独立删除/撤销与行动日志参与恢复。
- 体验：中文 Web、移动布局、明确同意的离线副本/草稿/待发队列、静态应用 PWA 缓存、通知中心/DND。Web Push 加密订阅与有界投递已实现；厂商/真机送达单独验收。

## 关键正确性边界

认证上下文决定调用者；消息正文、模型输出和外部 Agent 声明均不能授予权限。读取、执行和披露分别判定，执行前重验当前身份、版本、租约与全祖先约束。审批绑定固定动作，不能作为任意工具调用的长期通行证。

业务事务与 outbox 一起提交。重复请求使用原业务身份核对；外部请求结果不明时保留 unknown 和预算，禁止以盲目重发推断结果。恢复先隔离/冻结，重放独立事实并核对已发生的外部效果。数据库恢复不能撤回外部副作用。

浏览器缓存不承担认证或授权职责。退出和清除设备数据使迟到写入失效；联网后重新验证身份与范围。离线设备无法立即获知远端撤权，这一边界在主动启用缓存时说明。

## 验证与后续工作

回归分为单元/性质测试、真实数据库与协议集成、浏览器、本地模型、恢复演练和容量测量。可执行入口与具名用例索引见 [测试说明](testing/README.md) 和 [回归目录](testing/regression-cases.md)。具体次数与失败修复记录以 [测试报告](testing/test-report.md) 为准，不把目录中的声明数当作通过数。

当前尚需完成参考负载下的性能优化、完整 AC/INV 逐断言证据审查、生产部署可观测性与灾备验证，以及目标设备/真实外部供应方矩阵。该清单保留原 V1 验收范围，不能通过改写为“后续功能”自动解除门槛。

## 主体交付补齐

按“主体框架与完整流程优先”的开发顺序，新增本机集中启动器：保留既有配置、初始化基础设施/构建/迁移/种子、监督 API/Worker/Web 和可选工具执行器，检查就绪并统一停止。已实际验证双人消息送达、端口冲突拒绝以及 Worker 退出时整组退出。

新组织不再只能依赖固定开发 seed。离线 `workspace:provision` 使用已有有效 human 身份，在同一事务创建组织、工作区、唯一 owner 和初始成员，并保存仅运维可读的数据库操作者回执；同清单重试不会恢复已撤销权限。这是首次开户入口，日常组织管理台仍按 [后续优先级](delivery-backlog.md) 推进。

对 41 项 AC/INV 的本轮断言审查结果为 24 项 verified、16 项 partial、1 项 pending，详见 [逐项审查](testing/acceptance-review-2026-10-04.md)。已补私聊专用回归；剩余联合故障、竞争、兼容与真实部署验证逐项保留，不把功能试用候选描述为生产准出。
