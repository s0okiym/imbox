## 已验证的代表性路径

- 消息与同步：真实数据库并发写入、重试去重、固定快照与当前 ACL；真实 TCP WebSocket 重连；双人浏览器聊天、编辑、撤回、移动布局和丢响应恢复。
- 任务：真实数据库交接竞争、委派、全祖先失效、固定提交及验收；浏览器任务协作。
- Runtime：数据库时间租约、不可变上下文、旧代际拒绝、预算预占/待核对用量、检查点恢复；真实 Ollama 固定摘要的 `qwen3:0.6b` 调用。该小模型用例验证接入和用量闭环，不构成复杂任务质量保证。
- Action：真实 HTTP 工具先发生效果再断开连接，平台记录 unknown；只读核对确认原效果且未重复发送；签名文件日志与落盘失败回归。
- 外部 Agent：真实 HTTP + SDK + PostgreSQL，短期身份撤销、跨租户/伪造身份拒绝、仅 ACK 不接单、显式交接、人机分离的验收边界、丢响应后同一命令重试。
- 文件：真实 S3 + PostgreSQL 校验类型、大小、摘要、当前授权与删除。当前明确限制为纯文本、Markdown 和 JSON，单文件最高 8 MiB；不宣称通用二进制文件或杀毒能力。

新增模块接入后需重新运行全回归。所有最终结果必须绑定同一候选提交、迁移列表和依赖锁摘要。

## 验证与环境约束

- `tests/acceptance/coverage.json` 保留所有产品 AC/INV；只有真实实现、对应断言和运行证据齐备后才能标记 verified。
- 失败必须定位并修复；不能删除断言、静默 mock 或缩小原定 V1 范围来获得通过状态。
- 生产 OIDC、设备系统通知、生产连接器、WAL PITR 和设计容量仍需各自的证据，不与本地测试混写。
- 使用独立 Node 24 工具链、PostgreSQL 18（本地端口 55432）、SeaweedFS S3（18333）和 Ollama（11435）；不改动宿主原有 Node / PostgreSQL 或其他项目服务。
- `.env`、凭证、测试 trace、对象数据和模型缓存不提交。应用/Worker 使用非 owner 且无 BYPASSRLS 的数据库角色；数据库迁移由独立命令执行。
