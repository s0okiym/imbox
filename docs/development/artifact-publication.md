# 固定产物版本的外部发布

本功能推进 AC-18；当前分阶段实现，未完成浏览器创建与 Agent 绑定流程前不宣称完整准出。

## 授权与内容

ActionResourceRef 保留 TaskVersionRef，并加入 artifact_version：id 指向不可变 artifact_versions.id，version 是该内容版本号，sha256 为资源内容哈希。引用继承原任务范围，不能用引用扩大读权限或隐式披露到其他任务。授权签发者、请求者和执行者在各自准入阶段必须具备当前来源访问权。API 与独立工具执行器使用相同的知识来源适配器。

发布行动可绑定一个产物版本，parameters.text 必须与该版本的索引原文完全一致；4000 字符的既有文本工具上限继续适用，禁止自动截断或拼接多个产物。授权可以列出多个允许版本，行动明确选一个。批准指纹包含类型、版本 ID、版本号、SHA-256、完整参数、目标、工具修订和费用。新 head 不替换旧引用；新版必须在有效授权范围内新建或修订行动并重新审批。

## 执行与历史读取

创建、审批、领取和派发前沿用 Action 准入检查并重新读取固定来源。删除、撤权、哈希错误或来源适配器缺失均不能发送；持久意图之后被拒绝的未派发操作走既有 abortPrepared 释放流程。unknown 保持只读核对，不重新发送。

读取 Action 时重新验证当前查看者的产物读取权。来源不可用时 content_restricted=true，parameters.text 返回固定隐藏提示，保留状态、批准指纹与费用供核对；原始正文不通过列表或详情泄露。该字段不赋予执行能力。对象与旧授权恢复必须继续遵循原撤权规则。

## 待完成的完整流程

Web 创建授权现可分页选择任务产物与固定版本；提出行动时选择授权内版本并只读加载原文，审批页显示版本、哈希与全文。GET /v1/grants/{id}/publication-sources/{versionId} 重新检查当前查看者、授权状态和来源读取权限，仅返回授权中明确列出的产物版本。空内容或超过 4000 字符返回 413，不截断。Agent Run 工具授权现显式包含本任务与最多一个产物上下文，类型/版本/哈希按原类型映射；其他消息、Memory 等上下文仍不能隐式扩大外部披露。绑定授权时要求完整引用集合一致，执行前重新验证当前来源与祖先执行资格。人工审批之后仍须显式恢复并领取新租约。直接行动的真实浏览器授权/原文核对/审批/发布、Agent HTTP 及删除后 unknown 核对已有增量证据；仍需在新建 Run 表单选择含产物的工具授权，补齐该浏览器入口与剩余来源权限变化矩阵。当前功能不支持富文本渲染、任意文件发布或超过工具上限的自动摘要发布。

产物发布只允许配置为必须审批的工具；不能通过选择免审批工具绕过固定内容的人工确认。来源读取仍由原来源适配器验证任务范围、双方权限、版本与 SHA-256，工具引用转换本身不授予权限。
