# 工具连接配置与授权绑定

工具 ID、版本和目标 ID 是逻辑身份，不能单独证明部署配置仍指向签发时的外部连接。此前重启进程时在保留逻辑标识的情况下修改 URL，旧授权仍可通过检查；本轮补齐该执行边界。

HTTP 工具计算内部 executionBinding：对适配协议版本、规范化后的执行/查询 URL、完整执行定义与授权请求头作 SHA-256。快照只保存摘要，不保存连接地址或凭证明文，不通过工具目录或 Grant DTO 返回摘要。凭证变化可能代表不同外部账号，因此也要求重新授权；普通凭证轮换会同样失效，属于明确且保守的兼容边界。

签发授权将 tool_binding 写入既有 authority_snapshot。新建行动、审批、领取、派发所调用的 grantCurrent 比较当前连接绑定和签发快照。运行中固定参数仍来自已持久化 Action。批准指纹绑定 Grant ID/修订；配置摘要不能被请求者提供或更改。普通回执核对单独检查连接绑定，不要求失效或撤销的授权重新变为有效，以保留真实旧效果的只读核对能力。

适配器复制输入配置并冻结工具定义，调用者在注册后修改原配置对象不会改变已注册连接行为。更改 execute URL、lookup URL、凭证或执行策略均需要新建明确授权和行动；旧 unknown 不得以新行动自动补发。

## 升级与回退

连接摘要复用 JSONB 权限快照；后续迁移 036 为旧写入器增加数据库约束。旧授权没有 tool_binding，升级后拒绝用于新行动或继续派发，也不能自动把当前配置回填为历史批准的连接。尚未派发的行动应由用户撤销并重新授权；unknown 保留真实未决状态，旧版本缺失连接证据时须走独立恢复审查，不能为解除阻塞直接补摘要或重发。旧应用无法匹配带新字段的快照，因此回退也需要协调处理授权。

新版本创建的 unknown 在配置变化后保持 unknown 且不向新查询地址发送请求；恢复完全相同的原配置后可按原业务键只读查询。独立灾备账本恢复的供应方配置证明仍属于恢复准出范围，本改动不宣称完成生产恢复验收。

## 独立恢复账本

新执行意图在派发前将 tool_binding 写入独立签名账本，取值来自当前匹配授权的工具连接。孤立行动恢复使用此账本字段核对当前工具配置；不匹配或旧意图缺失字段时不调用供应方，查询证据保持 unknown，冻结不解除。恢复原连接后仍可按原租户/行动/尝试/业务键/指纹执行只读核对。幂等重写旧意图保留原始内容，不借重试回填缺失的历史连接证明。

## 旧执行器写入约束（迁移 036）

应用检查不能约束未升级的进程。迁移 036 在新授权插入、行动尝试插入/更新的事务提交时，重新读取最终行：新授权必须含 64 位小写十六进制连接摘要；最终仍为 prepared 或 in_flight 的尝试，其所属授权也必须包含该摘要。违反时整个事务以约束 action_connector_binding_required / SQLSTATE 23514 回滚。约束延迟到提交，兼容当前服务同一事务先插入授权再填充权限快照的流程；函数使用调用者权限及显式租户条件，不以 SECURITY DEFINER 绕过 RLS。

迁移不修改历史授权、尝试或账本，不把当前连接伪装成历史授权。旧 prepared 尝试不能转入 in_flight；failed、unknown、已完成等终态处理可继续，以便保留真实结果和释放未执行预留。约束仅证明摘要存在且格式正确，实际连接匹配仍由新应用和独立恢复账本验证。它不撤销已发出的 HTTP，也不替代应用升级或证明任意旧二进制均安全。

部署顺序：停止旧工具执行器和恢复写入服务，冻结外部行动入口并清点 in_flight / unknown；保存数据库与独立账本，执行迁移 036；一致更新 API、Worker、tool-runner、恢复程序及连接配置；核对已有外部效果后再恢复入口。旧授权必须重新显式授权，禁止自动补摘要。通信服务的旧/新 API 切换证据只覆盖消息与会话，不能据此允许旧执行器并行运行。

回退须保留迁移 036，并继续停止不理解连接绑定的工具执行器和恢复程序；有外部效果未决时不得直接恢复旧执行栈。恢复数据库备份可能同时移除该约束，必须先隔离写入、重新应用所需迁移并完成独立事实核对。迁移 owner、禁用触发器及任意数据库篡改不属于该应用角色约束的防护范围。
