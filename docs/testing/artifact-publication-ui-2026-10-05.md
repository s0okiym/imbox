# 固定产物发布的 Web 授权与提案

日期：2026-10-05（Asia/Shanghai），父候选 bbc2690。

创建工具授权可按任务选择产物与历史固定版本，两个列表均有分页入口；切换任务/产物清除选中版本和披露确认。提出行动时从授权内选择一个产物版本，调用新的只读来源接口加载完整原文，正文不可编辑，变更内容需新版本/重新授权。提交使用实际选定的固定引用，不自动改为新 head。缺失原文、读取失败或未核对时不能提交。页面始终按文本显示，不执行 HTML/Markdown。

来源接口只读取当前主体有权查看、当前授权明确包含的版本，当前授权失效或资源撤回时拒绝。超出 4000 字符或空原文返回 PUBLICATION_TOO_LARGE/413，不提供截断替代。服务侧仍在新建、批准、领取和派发时验证来源与参数，不依赖只读 textarea 的客户端限制。

浏览器测试使用真实 S3、PostgreSQL、API 和受控外部 HTTP：选择 v1 并签发授权，随后服务端追加 v2，页面提出行动仍读取 v1 全文，人工核对批准后只发送 v1；丢回执进入 unknown，查询既有回执后成功且没有第二次发送。另保留普通文本授权/审批流程回归。

首轮浏览器测试的 getByLabel exact 选择器未能定位含选项文本的 label；可访问性快照显示下拉框存在。改用 getByRole('combobox', { name, exact: true })，未增加超时或删减业务断言。

尚待：新建 Agent Run 表单绑定含产物的授权及其浏览器完整流程、更多撤权/哈希边界组合。当前不将 AC-18 提升为全部 verified。

第二轮浏览器复验定位到真实 HTTP 边界缺陷：Fastify 参数对象带框架原型，直接传入严格 JSON 契约校验器会令合法预览请求返回 400。路由现在先复制已由路由 schema 校验的自有参数到普通对象，再调用契约校验；未放宽全局 JSON 原型限制。服务集成无法覆盖该框架边界，保留完整浏览器复验。

本轮完整 verify 通过，191 单元（11.02 秒）；Action 集成先 24 项通过（26.48 秒），增加 4001 字符拒绝用例后 25 项通过（27.27 秒）。API 参数转换修复后单独重建 API，浏览器结果另列。

原文填入 textarea 后也会进入 label 的 DOM 文本，复验同样将该测试定位改为 textbox 的可访问名称；HTTP 已返回 200，页面快照含正确旧正文且 readonly。保持完整正文与发送断言，不延长等待期限。
