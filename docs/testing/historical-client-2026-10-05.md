# 历史 Web 制品连接当前服务端

日期：2026-10-05（Asia/Shanghai），当前服务端父候选 91c2542；历史前端固定为 2f751069fc11062f48cfd5d377db2970e9088268，该提交此前已有归档 CI 证据。

`pnpm test:compatibility` 从完整 Git SHA 导出独立源码，以历史锁文件离线安装依赖，构建历史 contracts 和 Web。当前与该历史锁文件的外部包版本一致，差异仅为工作区包引用；首次环境须先完成根仓库安装。每个构建文件计算 SHA-256，写入本机 .artifacts 下的 client-build.json；测试读取并核对提交身份与实际服务字节。CI 获取完整历史并执行独立兼容性步骤，保留原凭证输出脱敏规则。

同源测试服务器通过独立上下文的测试 Cookie 选择历史或当前生产静态制品；启动时校验历史 manifest 与每个文件 SHA-256，并在静态响应标识实际客户端提交。HTTP API 与 WebSocket 原样代理到当前真实服务。两个前端均未经代码改写，通过测试 API 建立会话后加载生产构建；不依赖生产中被禁用的开发登录按钮。这不是生产 OIDC 登录验收。

场景覆盖：历史 Alice 创建会话、向当前 Bob 发送消息，Bob 实时回复；在真实快照中注入未来展示实体（包括伪造执行命令和脚本摘要），历史客户端显示固定安全提示，不展示私密载荷、不执行脚本；随后继续发消息并由当前客户端接收。旧页面无未处理异常。Service Worker 在该测试中关闭，因此不把此结果用于离线缓存迁移或旧 SW 更新证明。

首轮因等待历史生产构建不存在的开发登录按钮而超时，随后改为测试接口建立会话，未改动历史制品、未延长超时或删除业务断言。复验通过：场景 13.0 秒，含启动共 27.6 秒。当前客户端的原“older client”测试标题改为 current client，避免把当前实现的注入测试当作历史制品验证。

完整命令复验曾发现旧页面没有发出消息 POST；增加真实发送响应断言后，追踪确认旧页 WebSocket 被 Chromium 的 ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS 阻止。原因是静态页面响应拦截引入了网络来源差异。测试改为真实同源静态服务器和 HTTP/WebSocket 代理，不禁用浏览器安全功能、不修改历史制品；发送前等待实时同步，并验证 POST/201、发送端已保存与接收端可见。早期 13.0 秒通过结果不能替代该修正后的复验。真实同源服务下的完整命令通过，浏览器场景 10.4 秒、含应用启动 23.1 秒（不含前置构建）。最终静态路径限制及类型复查后的浏览器结果另列。构建身份与文件摘要见 [制品清单](historical-client-build-2026-10-05.json)。

AC-21 保持 partial：该记录只证明一个明确历史客户端与当前服务端组合，服务端滚动替换、历史 Action schema 和更多客户端代际仍需验证。更早未实现安全降级的客户端不由本结果推定兼容。

最终代码复验通过：历史兼容浏览器 10.2 秒，含应用启动 23.1 秒；测试类型检查、构建与服务脚本/配置/测试的 Lint 通过。回归目录 88 文件、529 条声明。未修改历史前端源码或关闭浏览器本地网络保护，未提升 AC-21 状态；后续滚动服务端与动作 schema 验证独立进行。
