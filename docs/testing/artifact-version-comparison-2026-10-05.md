# 固定 Artifact 版本内容比较

日期：2026-10-05（Asia/Shanghai），基于 61b4107。Web 新增两个固定版本的内容比较，不修改权威产物或审批数据。

用户明确选择版本后，从现有鉴权下载入口读取两个资源，复用长度/摘要校验。文本按实际 UTF-8 内容比较，保留 BOM、行结束符与末尾换行；Markdown/JSON 作为文本展示。共同起止行之外的变化范围并列显示，中间未变化的行也可能保留，界面不宣称最小差异。切换版本或卸载视图会取消读取并清空旧结果。

性能边界：每个版本在线比较上限 256 KiB；每侧变化预览最多 12,000 个 Unicode 字符。超限和截断均明确提示下载完整版本，不显示虚假的“全部相同”。此上限只限制在线比较，不修改既有 8 MiB 上传上限。

已运行验证：

- 34 文件、191 单元测试通过，9.23 秒。新增 3 用例覆盖插入/多处修改、共同前后行、空文本、CRLF/LF、末尾换行、BOM、Unicode 无断裂截断及相同内容。
- 四项资源浏览器测试全部通过，55.9 秒。真实上传的 v1/v2 比较显示各自实际字节内容；切换目标为 v1，比较显示完全相同。既有固定证据验收、附件删除、分享撤回及跨作者追加/降权流程继续通过。
- Web 类型、测试类型和涉及文件 ESLint 通过；回归目录更新为 87 文件、496 条声明（不是执行通过数量）。

未完成范围仍包括分支/合并、外部发布 Action 的旧批准/新版产物联合矩阵及更大文件的在线比较。AC-18 保持 partial；整体准出门禁状态不提升。
