# 独立外部 Agent 进程暂停与恢复演练

日期：2026-10-05（Asia/Shanghai）。父候选 1e20482；本轮新增进程级回归，不改变产品执行逻辑。

测试通过 Node fork 启动独立 OS 进程，子进程使用实际 TypeScript SDK 和 HTTP 兑换凭证、领取 Run，启动可停止的本地工作循环。凭证经私有 IPC 传入，不放进命令行、不继承数据库环境、不输出 stdout/stderr；父进程只接收运行代际和非敏感状态。

Linux SIGSTOP 暂停进程后，通过 /proc 状态确认实际停止。平台请求取消，Run 为 cancelling，停止确认仍为空。测试只读轮询 PostgreSQL 的真实租约时钟，等待默认 60 秒租约自然到期，没有更新 lease_expires_at 或 created_at 来缩短期限。

SIGCONT 恢复后，子进程先停止本地工作循环，尝试提交 completed 输出得到 409，再通过迟到确认通道报告停止并正常退出。父进程验证 PID 与 API 不同、确有本地工作执行、进程退出码为 0、运行取消且确认时间匹配、代际未恢复、output 仍为空、run_reports 没有迟到结果记录。失败路径会恢复并终止测试子进程，避免留下暂停进程。

验证：测试类型、两个新增/修改测试文件 ESLint 通过；agents 集成 14/14 通过，85.89 秒。该用例为真实 60 秒等待设置 120 秒总期限，没有以增加超时掩盖失败。回归目录 87 文件、504 条声明。本用例仅在 Linux 运行，其他平台明确跳过；当前 Linux 环境和 GitHub Ubuntu CI 是必跑路径。

证据边界：独立 Agent 与 API 是不同进程，但位于同一主机并使用 loopback HTTP。本测试证明进程停顿、真实租约到期、恢复后的执行拒绝及停止确认；不证明跨主机 TLS、网络分区、主机重启或任意 Agent 外部副作用已停止。Agent 的确认仍标记 external_report，测试进程退出是测试侧观察。

本轮审查另发现 Task 取消目前通过任务状态/执行代际阻止新执行，但取消命令没有同步更新相关 Run 的取消请求/显示状态。下一步需补齐该联动，不能用这里的 Run 级取消替代 Task 级完整路径。AC-14 保持 partial。


## Task 取消联合路径补充

父候选 41f3e12。同一 Linux 独立进程演练现参数化为 Run 取消与 Task 取消两种入口。Task 路径通过真实 Task 服务创建任务、授权 Agent 为 contributor、推进 active，并将当前 Task 版本作为 Run 的固定输入。进程暂停后取消 Task，再验证 Run 收到取消请求、真实租约自然到期、恢复后的 completed 输出被拒绝、迟到停止确认成功且进程退出。它将前两轮分开的任务联动与进程失联演练组合为一条实际路径，保留原 Run 取消覆盖。

这仍是同主机、独立进程、loopback HTTP 的测试；不将两个进程描述成跨主机部署，也不将 Agent 自报停止描述成普遍的远端停止保证。

联合路径验证：agents 集成 15/15 通过，150.77 秒；两个进程场景均等待实际 60 秒租约自然到期。测试类型、修改文件 ESLint 通过。回归目录仍为 87 文件、507 条声明；本轮参数化增加了实际执行场景而未增加声明数。
