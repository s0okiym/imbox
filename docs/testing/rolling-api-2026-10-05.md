# 历史 API 与当前 API 的连接切换验证

日期：2026-10-05（Asia/Shanghai）。当前生产代码父候选 83249da；历史 API/Web 均来自固定提交 2f751069fc11062f48cfd5d377db2970e9088268。

历史构建脚本新增 API 与其工作区依赖构建，仍使用原锁文件离线安装。manifest 保存 API 入口 SHA-256，启动器核对完整提交与入口哈希后启动独立旧 API 进程（4111）；当前 API 为 4110。两者使用当前测试数据库、相同会话签名配置与当前分发 Worker。该过程不回退数据库迁移，也没有把当前 API 源码伪装为旧版本。

同源测试代理提供仅本机可用的后端切换控制，选择历史/当前固定端口并关闭现有代理 WebSocket。客户端保持打开，自动重新连接；静态客户端版本由各自隔离上下文选择，与后端选择独立。测试先在旧 API 登录，旧客户端发消息，新客户端收到；切换当前 API 后双方分别发送；回退旧 API 后当前客户端继续发送；最后两端刷新，四条消息分别只出现一次。全程不重新登录，不重新创建浏览器上下文，不提高超时，不关闭浏览器网络安全检查。

完整兼容性命令通过：两个 Chromium 场景合计 46.9 秒含应用启动，既有历史展示降级场景 10.9 秒，API 切换/回退场景 17.3 秒。构建耗时不包含在该浏览器时间中。测试类型与相关脚本/测试 Lint 通过。

另扩展真实 Action HTTP 测试：未知 schema_version、新参数属性、参数类型变化及未知 v2 媒体类型均应拒绝，保留原版本/全文/指纹/ready 审批；之后合法内部执行仍只发送原批准内容一次。当前服务把这些不兼容输入统一返回 400。Action 集成文件 50/50 通过（37.52 秒）；四个新拒绝输入在既有 HTTP 用例内验证，不另算四个测试声明。该项使用当前 HTTP 服务，不声称是旧 API 的 Action 控制矩阵。

范围：这是本机双 API 实例的通信读写和会话兼容性、连接中断/回退验证，不是所有业务模块的生产滚动升级验收。未模拟节点故障、数据库迁移竞争、混合 Worker 升级、旧 Action 连接授权或旧恢复服务写入；尤其不得绕过既有连接摘要升级限制。AC-21 保持 partial，完整控制动作与部署兼容策略需继续审查。
