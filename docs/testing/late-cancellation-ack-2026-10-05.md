# 租约过期后的独立停止确认

日期：2026-10-05（Asia/Shanghai），父候选 56d7cbc。新增迁移 035、机器 HTTP 契约、执行器受限命令与 SDK 方法。

独立命令核对当前机器身份/授权和服务端持久保存的最后领取 Worker/代际，只接受已请求取消且无有效租约的取消中/已取消/过期运行。响应仅 run_id、generation、acknowledged_at 与 external_report 来源，不返回源上下文、输出或运行正文。过期状态保持；租约已过期的取消中运行可终止为 cancelled。

实际回归覆盖：

- 未请求取消、仍有有效租约、被替代代际、其他 Agent、同 Agent 替换凭证均不能提交确认；正文注入 output 返回 400。
- 有效迟到确认、原键重放和不同键重复确认返回同一时间，仅一个确认事件，审计主体是实际 Agent。
- 确认后领取、心跳和 completed 输出报告仍拒绝；不恢复执行资格。
- 通过真实预算服务保留 5 microunits 预占，确认后 held 状态、预占金额与未定实际费用原样保留，不伪造费用结算。
- 原报告协议仍拒绝已过期 Worker；平台直接取消后可通过新通道确认。维护器因总期限到期增加围栏代际并标记 expired 后，最后实际领取代际仍可报告停止，运行保持 expired 和原预算。
- 凭证撤销后，即使重放曾成功的确认也返回未认证。

验证：`pnpm verify` 通过，34 文件/191 单元（9.05 秒）；最终 agents/runtime 两文件 36/36 集成通过（32.82 秒），测试类型与 ESLint 通过。集成测试使用真实 PostgreSQL、HTTP 和 SDK；到期边界由测试数据库时钟条件构造，不是跨机器断电演练。本轮未改 Web 显示，其停止确认展示沿用上一候选已测路径。
