# 任务 Artifact 的多人版本编辑

日期：2026-10-05（Asia/Shanghai）。基于 de61763，新增真实功能，不仅补充测试。

当前任务 owner/contributor 可追加任务产物版本，reviewer/observer 不可写；会话产物保持创建者专属编辑。Artifact 本身保留最初创建者，每个不可变版本记录实际提交者。每次写入在现有任务权限/祖先状态检查、任务根锁及 Artifact 版本锁下完成。新增可选响应字段 can_append_version 给 Web 显示当前编辑入口，缺少字段则隐藏；提交仍重验权限。

实际验证：

- 三个资源集成文件 29/29，通过真实 PostgreSQL/S3（31.50 秒）。Alice 创建，Bob 作为 contributor 追加并记录 Bob 作者；Charlie reviewer 不可写。Alice/Bob 同时使用同一版本提交不同字节，仅一人成功，另一人 VERSION_CONFLICT。Bob 降为 observer 后，已有成功命令的幂等重放和新的追加均拒绝，版本数不增加；会话成员不能编辑他人会话产物。
- 33 个单元文件、188/188，通过（8.61 秒）。
- resources.spec.ts 四个真实浏览器流程全部通过（58.6 秒），包含负责人创建→Bob 登录→上传版本二→下载核对字节→角色降权→刷新后编辑入口消失。原有固定证据验收、附件删除和受控分享流程也通过。
- 工程检查中的环境、契约生成、构建、运行依赖、包类型与测试类型检查通过。首次 lint 发现测试赋值未使用，修正后又发现改为 const 的要求；最终单独复核 lint 与测试类型。未将最初中途退出的 pnpm verify 标为一次通过。

无需数据库迁移。已有任务产物也遵循任务写权限；分配 contributor 即授予任务产物追加能力。分享与资源删除仍有独立权限限制，协作者编辑不自动赋予这两项能力。

范围尚未完成：Artifact 分支/合并、类型差异比较及外部发布 Action 的旧批准/新版产物组合。AC-18 保持 partial，生产验收继续 27 verified / 13 partial / 1 pending。历史证据中“仅创建者可编辑”描述的是本变更前的候选。
