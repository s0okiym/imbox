- 当前服务准备已审批行动，构造历史无摘要授权后调用历史 runner.runOnce；领取事务失败、行动仍 ready，HTTP 请求为零。
- 当前服务先准备尝试并持久化意图，再构造历史无摘要授权；历史 dispatch 在提交 in_flight 时失败，尝试仍 prepared。随后历史 abortPrepared 成功进入 failed，HTTP 请求为零。
- 对当前正常签发的有绑定授权，历史 runner 因不匹配旧权限快照而拒绝，HTTP 请求为零；同一已批准行动由当前 runner 执行成功，真实 HTTP 请求恰为一次。
