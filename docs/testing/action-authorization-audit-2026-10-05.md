# AC-12 / INV-08 当前授权与精确审批审查

日期：2026-10-05（Asia/Shanghai），父候选 6f2a919。生产实现保持父候选不变，补充撤销授权的三个业务阶段测试并统一审查现有断言。

## 原始要求

AC-12 要求批准后撤权、修改任务或资源版本时，执行前重验失败并停止；已提交外部动作显示真实边界。INV-08 要求审批绑定动作版本、目标、关键参数、执行主体和期限，并在真正执行前验证当前授权。对照设计第 13.3 节，平台不能撤回已发送至第三方的请求；这必须反映为真实的未知/已发生状态。

| 条件 | 权威实现与已执行断言 |
| --- | --- |
| 动作版本和参数 | fingerprint 包含 Task、executor、Grant ID/修订、工具/版本/目标、完整参数、来源版本、币种与预估；reviseAction 撤销旧审批、改变绑定版本。参数及已授权新版产物修订后旧批准拒绝，重新批准才可发送。 |
| 目标与执行主体 | HTTP 拒绝向修订输入注入目标、工具、版本、执行者，保持原批准绑定；grantCurrent 比较这些固定字段，actors 比较当前主体与安装代际。机器 API 验证 scope、凭证持有人及当前租约，不允许机器批准或自行恢复。 |
| 实际连接配置 | Grant 快照比较规范 URL、凭证和执行定义摘要。相同逻辑 ID 下重配置仍拒绝旧授权；持久意图后换地址拒绝。普通核对和孤立恢复也不向新配置查询旧回执；签名意图记录原连接。 |
| 当前批准者 | 独立 Charlie 批准而 Alice/Bob 保持不变，通过正式管理接口停用、恢复、降权；Task 版本不变。领取前和持久意图后均拒绝，零外部调用。 |
| 期限 | Grant、approval 分别覆盖领取前和持久意图后到期；执行租约保持有效仍不能发送。独立测试还拒绝过期租约。 |
| 授权撤回 | 新增固定产物授权在领取前与持久意图后撤销均拒绝，零 HTTP 和零费用，后者释放预占。 |
| Task 版本 | 标题更新不改变 epoch，单独使 Task 资源版本过期；领取前/持久意图后均拒绝，零请求，旧预占释放。另有真实交接/祖先代际围栏验证。 |
| 产物版本与来源 | Action 当前支持 Task 和 artifact_version 两种引用。产物 ID/版本/哈希错误拒绝，正文必须等于固定原文；新 head 不改不可变旧版，明确换版必须重新批准。来源删除/执行者移除在两个阶段均阻止外发。 |
| 已发生外部效果 | 真实 HTTP 效果发生并挂住回执时执行交接或撤销 Grant；丢回执后保留 unknown，禁止重发，原连接核对后只结算一次。来源删除也隐藏正文但不伪造“未发生”。 |

审查覆盖本 V1 的实际 Action 引用类型与绑定维度，没有将无限笛卡尔测试组合当作完成定义；也没有把该项提升解释为真实 IdP、生产恢复、全部供应方或跨主机故障验收。执行准入与实际第三方系统之间不承诺分布式原子撤回。
