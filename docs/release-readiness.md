## 解除阻断的证据

1. 固定被测源码身份、依赖锁摘要、迁移清单、运行环境和测量时间。
2. 全量检查通过；修复后重跑相关路径，并确认未掩盖失败、跳过测试或替换为模拟成功。
3. 按 AC-01～25 / INV-01～16 逐项审查真实断言与拒绝/并发/恢复路径，记录证据，不批量按文件名置为 verified。
