# Imbox V1 准出记录

日期：2026-10-04。结论：**尚不准出**。当前交付为持续开发候选，不能描述成已完成生产验收的 V1。

| 门槛                   | 当前证据与结论                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| 工程、类型、契约与单元 | 同一源码指纹下工程全检与 180 项单元通过，结果见测试报告。                                                     |
| 真实集成与浏览器       | 当前候选完整集成 236 项、浏览器 24 项全部通过；不代替尚未完成的生产/容量门槛。                                |
| 模型与外部行动         | 本地固定模型真实推理、受控 HTTP 工具丢响应/核对已验证；实际部署模型质量和外部供应方仍需各自验收。             |
| 数据恢复               | 隔离 PostgreSQL dump/restore、对象恢复和独立隐私事实重放有实测；生产 WAL PITR、RPO/RTO 和完整授权审查未完成。 |
| 容量                   | 百万历史/千连接已实测但延迟未达标；参考身份分布、重连风暴、模型/文件竞争仍待验证。不得只报成功样本 P95。      |
| 客户端支持             | Chromium 与移动视口已有回归；真实 iOS/Android、辅助技术与厂商系统推送待验证。                                 |
| 安全不变量与 AC        | 41 项登记在 coverage.json，仍待逐断言审查和候选证据绑定。静态登记不等于 verified。                            |
| 运维                   | 本地环境与操作手册已有；生产 TLS/IdP、指标告警、备份设施与发布回退演练待完成。                                |
| 制品与远程             | 需要将源码、锁文件、迁移及测试证据关联到可识别候选，并核对远程与 CI；推送代码不等于发布。                     |

## 解除阻断的证据

1. 固定被测源码身份、依赖锁摘要、迁移清单、运行环境和测量时间。
2. 全量检查通过；修复后重跑相关路径，并确认未掩盖失败、跳过测试或替换为模拟成功。
3. 按 AC-01～25 / INV-01～16 逐项审查真实断言与拒绝/并发/恢复路径，记录证据，不批量按文件名置为 verified。
4. 在参考负载完成保存/可见/补齐延迟与错误、缺失、重复计数，完成竞争场景；当前不达标结果仍保留。
5. 在目标部署与设备完成实际身份提供方、TLS、厂商推送、独立账本与备份恢复、告警和回退验证。

操作入口见 [运维手册](operations/README.md)、[系统推送](operations/web-push.md)、[容量工作记录](testing/capacity-report.md)。没有满足这些门槛前，`pnpm test:acceptance` 应保持失败，不能为了 CI 绿灯删除门禁。
